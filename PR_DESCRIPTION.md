## 🔴 Критично (безопасность и целостность данных)

### 1. RBAC — рассинхрон ролей и дырявые проверки прав
- **Баг:** `home_page.py` сравнивал роль с `"admin"`, тогда как в БД хранится `"Администратор"` — часть проверок никогда не срабатывала.
- **Уязвимость:** `RoadmapExpertPage` не проверяла права вообще — любой пользователь мог подтверждать заявки на баллы (вектор: самостоятельное начисление себе баллов рейтинга).
- **Решение:** создан единый модуль `app/authz.py` (`require_admin`, канонические имена ролей). Серверные проверки навешаны на `UsersPage`, `LogsPage`, `RoadmapExpertPage` и мутации. Тесты: `tests/test_authz.py`, `tests/test_security.py`.

### 2. Тихая порча данных при удалении заявок Road Map
- **Баг:** `decide(status="deleted")` лишь помечал статус, но заявка продолжала учитываться в расчёте баллов и отчётах.
- **Решение:** физический `DELETE` + регрессионный тест в `tests/test_photo_and_delete.py` и `tests/test_roadmap_flow.py` (защита от возврата бага).

### 3. Несуществующая колонка `roadmap_reviews.created_at`
- **Баг:** запрос уведомлений читал колонку, которой нет в схеме → падение/пустые уведомления.
- **Решение:** идемпотентная миграция `ALTER TABLE ... ADD COLUMN created_at` в `app/database.py`.

### 4. Молчаливые `except Exception: pass` (39 мест)
- **Решение:** введён `app/utils_logger.py`; тихие catch заменены на логирование с контекстом (`database.py`, `personal_file_page.py`, `report_generator.py` и др.). Найден и исправлен реальный баг: `report_generator.py:51` падал бы `NameError` внутри обработчика ошибки отсутствия шрифта.

## ⚡ Производительность

### 5. N+1 на странице премий
- **Было:** цикл по курсантам с отдельными SQL-запросами на каждого.
- **Стало:** батчевые выборки с оконными функциями в `app/repositories.py`; запись в аудит-лог вынесена из цикла.

### 6. Фото курсантов в base64 внутри БД
- **Решение:** новое хранилище `app/photo_storage.py` (файлы на диске, БД хранит путь), обратная совместимость со старыми base64-записями, идемпотентная фоновая миграция `migrate_legacy_base64()` (вызов в `main.py`), `.gitignore` для `data/`.
