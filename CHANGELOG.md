# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Пагинация списков курсантов и журнала действий с фильтром по дате (C-1).
- Кэш справочников групп/курсов `app/cache.py` с точечной инвалидацией (C-4).
- Контекстный менеджер транзакций `database.transaction()` и режим WAL (A-3).
- Консольная диагностика `python -m app.doctor`: целостность БД, hash-цепочка
  журнала, резервные копии, версии зависимостей, состояние фотохранилища (D-5).
- Резервное копирование БД при старте с ротацией 10 копий (A-4).
- Серверная проверка прав во всех мутаторах (`require_role`, B-1), политика
  паролей и блокировка учётки при переборе (B-2), неизменяемый аудит-лог с
  hash-цепочкой (B-5).
- Экспорт личных дел, списков и приказов в DOCX — `app/docx_export.py`
  (F-1/F-2): шаблоны приказов о поощрении/взыскании с автоподстановкой ФИО
  в родительном падеже.
- Импорт курсантов из XLSX — `app/xlsx_import.py` (F-5): шаблон → валидация
  строк → пакетная атомарная вставка внутри `transaction()`.
- Файловое хранилище фото `app/photo_storage.py` (C-3): ленивая конверсия
  legacy base64, идемпотентная `migrate_legacy_base64()`, `vacuum_database()`
  после подтверждения миграции.
- Секреты через `.env` + python-dotenv, образец `.env.example` (B-4).
- Покрытие: E2E-сценарии RBAC (T-1), тесты миграции legacy-хешей паролей
  (B-3), тесты пагинации/кэша/транзакций/doctor, метрики coverage в CI
  (`pytest --cov=app --cov-report=term-missing`, T-4).

### Changed
- SQL из UI-страниц вынесен в `repositories.py` / `database.py` (A-1).
- Публичные функции `database.py` аннотированы типами (A-5).

## [1.0.0] - 2026-10
### Added
- Первый рабочий релиз: «Канцлер Про» — объединённое приложение Kanzler + МКР
  «Дорожная карта» на Flet + SQLite: учёт курсантов, Road Map, рейтинги,
  поощрения/взыскания, отчётность (PDF/XLSX), роли «Администратор/Курсант».
