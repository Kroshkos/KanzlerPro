# Канцлер Про

Единое приложение, объединяющее функционал двух проектов:

* **Kanzler** — учёт курсантов и личный состав (точка входа и архитектура взяты отсюда):
  личные дела (~120 полей), кадровая работа (должности/звания), учебная работа
  (сессии, оценки), ВПР (поощрения/взыскания), премии, поиск, пользователи,
  журнал действий, авторизация с PBKDF2-хешами паролей.
* **MKR («Эксперт Дорожной карты»)** — модуль «Дорожная карта»: справочник
  достижений (с импортом CSV), экспертные решения с коэффициентами и расчётом
  итоговых баллов, индивидуальные планы развития (ИПР), статусы
  «кандидат/резидент», средние баллы семестра, ручные баллы по блокам.

## Интерфейс

GUI переписан в современном стиле: светлая flat-тема, карточки показателей (KPI),
чипы статусов, прогресс-бары по блокам достижений, топ-10 студентов, лента
журнала действий. После входа открывается **дашборд** с боковой навигацией во
все модули; классическое кнопочное меню Канцлера сохранено и доступно одной
кнопкой.

## Быстрый старт

```bash
pip install -r requirements.txt
KANZLER_ADMIN_PASSWORD=вашПароль python main.py   # Windows: set KANZLER_ADMIN_PASSWORD=...
```

При первом запуске создаётся чистая база `data/kanzler_pro.db` (данные
старых систем не мигрируются — программа заполняется заново) и пользователь
`admin`. Если переменная окружения не задана, временный пароль генерируется
и выводится в консоль один раз.

## Структура

```
main.py            — точка входа (Flet)
app/
  config.py        — пути и настройки
  database.py      — схема SQLite: таблицы Kanzler + Дорожной карты в одной БД
  repositories.py  — слой репозиториев (параметрический SQL, защита от инъекций)
  security.py      — хеширование PBKDF2
  theme.py         — визуальная тема (карточки, чипы, шапки)
  pages/           — страницы: дашборд, кадры, учёба, ВПР, премии, Road Map…
```

## Формула баллов Дорожной карты (наследие MKR)

* тип `ms`: баллы × К-уровень × К-роль × К-вид × К-статус + бонус ИПР;
* тип `month`: то же × количество месяцев;
* тип `grant`: размер гранта в рублях;
* тип `avg_score`: базовые баллы без модификаторов.

## Рейтинг Дорожной карты (перенесено из MKR)

Раздел «Рейтинг Road Map» — таблица мест курсантов по накопленным баллам
с фильтром по семестру и группе. Ступени системы (пороги унаследованы из MKR):

* **Активист** — ≥ 75 баллов за семестр;
* **Кандидат** — ≥ 150 накопленных баллов (+ заявка);
* **Резидент** — ≥ 250 накопленных баллов (+ утверждение).

Сводные карточки показывают распределение по ступеням и охват системой.

## Печатные отчётные формы (перенесено из MKR)

Раздел «Отчётные формы» формирует документы в Excel (.xlsx, openpyxl)
и PDF (.pdf, reportlab с кириллическими шрифтами Windows/Linux/macOS):

| Форма | Содержание | Параметры |
|-------|------------|-----------|
| Р-1 | Индивидуальный отчёт курсанта за семестр (решения, баллы, блоки) | курсант, семестр |
| Р-2 | Ведомость семестрового рейтинга группы | группа, семестр |
| Р-3 | Сводный отчёт по группе: ступени + блоки достижений | группа, семестр |
| Р-4 | Сводный академический отчёт по системе (план/факт) | семестр |
| Р-5 | Отчёт о ходе выполнения ИПР | курсант, семестр |

Готовые файлы сохраняются в `data/reports/` и автоматически открываются
стандартной программой ОС; список последних отчётов виден на странице.
Для PDF требуется `pip install reportlab` (уже в requirements.txt).
